# MSCS532 Assignment 4: Heap Data Structures

Python implementation of **heap sort** (Part 1), a **priority queue**
on the same binary max-heap with a `Task` class, and a
task-scheduling simulation (Part 2), from Chapter 6 of Cormen,
Leiserson, Rivest & Stein, *Introduction to Algorithms* (4th ed.,
2022).

The repository will also contain a benchmark that compares heap sort
against merge sort and quick sort on sorted, reverse-sorted, and
random inputs, measuring execution time and peak memory.
